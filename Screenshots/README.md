### Alarm Setup

Alarm configuration includes time selection, repeat scheduling, sound selection, snooze behavior, mission recall, and wake challenges.

### Challenge Types

SnoozeLock supports Math, Typing, Step Count, and Barcode Scan challenges. Step Count and Barcode Scan demonstrate integration with native device capabilities.

### Challenge Stacking

Multiple challenges can be configured as a sequential workflow. The example above requires a Math challenge followed by a Step Count challenge before the alarm workflow is complete.
